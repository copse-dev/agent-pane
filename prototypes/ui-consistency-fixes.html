01 · PR description font typography

Chat and side-chat prose use --font-prose because Pliant's tight word-gaps hurt long-form reading. .pr-viewer-description sets no font, so it falls back to Pliant — the PR body reads tighter and denser than the chat message right above it.

03 · Superseded model row states

A selected model that has since been superseded is marked disabled, which drops it to 50% opacity — so the model you're actually running looks like the dimmest, most unavailable row in the list.

Before — opacity 0.5
Recent
The checked row and "disabled" both use opacity, so the currently-running model reads as broken rather than selected.
After — fill, not opacity
Recent
Full-strength selected fill, plus a muted note explaining the successor — selectable rows are never dimmed.

05 · One search field kit gap

Seven surfaces each style their own search/filter input: the PR filter has no icon and inherits the 14px body font; the sidebar search is a rounded pill at 12px with an icon; Roadmap's is a filled box with no border. None share a recipe — there's no .ui-search in the kit.

06 · Pane header wrap layout

.pane-header carries flex-wrap: wrap for Roadmap's toolbar, but every pane shares the class — so "Pull requests" drops its refresh icon to a second row under modest width, growing past --pane-header-band-height and misaligning with the pane beside it.

After — wrap opt-in

Default is flex-wrap: nowrap; only Roadmap's header opts into wrapping for its extra toolbar row.

07 · Active-state weight shift states

Section tabs add font-weight: 600 on the active state. Bold text is wider than regular at the same size, so the active tab's label — and everything to its right — shifts a few pixels the moment it's selected. Click the tabs below to feel it.

Before — bold on select
Click a tab — the underline and every tab after it visibly jogs sideways as labels re-flow.
After — weight reserved
Colour and the underline carry the selection; a hidden bold copy reserves the width so nothing moves.

08 · Group header rhythm tokens

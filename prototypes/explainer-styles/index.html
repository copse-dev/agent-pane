Six ways to explain Copse, in motion

Each direction picks one real Copse problem and tells it as problem → action → result with everyday objects, readable labels, and visible cause and effect. No signal displays, no hand-drawn forest, no mascot. Two are animated below so we can judge motion, not just stills.

Animated samples (strongest two)

1 · Paper Desk — open live

2 · Isometric Mailroom — open live

  • Why these two: they explain the two hardest-to-picture features (reviewing edits, parallel subagents) with objects everyone already understands (stamped paperwork, a warehouse with carts). Their labels carry the meaning, so the story survives with sound off.
  • They contrast on purpose: flat top-down paper with snappy slide-and-thump motion vs. isometric solids with continuous parallel travel. Both use only the Copse palette.
  • Build notes: each frame is a pure function of time (runtime.js), so the same scene autoplays in a page and renders to MP4/GIF with capture.mjs. That is the seam a reusable generator could grow from.

All six directions

1 · Paper Desk animated

Cut paper · top-down · soft shadows · snap-and-thump
Problem
The agent edited three files; you can’t tell what changed.
Action
Edits land as diff sheets in a Changes tray; a rubber stamp marks Accept or Reject.
Result
Accepted edits go in the project folder; the rejected one reverts.

2 · Isometric Mailroom animated

Isometric solids · warehouse · continuous parallel travel
Problem
One agent searches a big codebase aisle by aisle; other aisles wait.
Action
Task slips go to three subagent carts that scan their own shelves at once.
Result
Each returns a note; the agent gets one answer: auth/session.ts:42.

3 · Blueprint Drafting Table

Cyan ink on blueprint · dimension lines · lines draw themselves on
Problem
The agent wants to read a file outside your project fence (e.g. ~/.ssh).
Action
A gate in the fence shows a padlock and an “Allow once?” tag; your pen ticks it.
Result
Only that one door opens, this once; the rest of the fence stays drawn solid.

4 · Riso Print Shop

Two-ink overprint · halftone grain · press passes at 12 fps
Problem
Most tools route your code through their own server before the model.
Action
A Copse envelope is printed and posted straight to the provider mailbox you picked (cloud or local).
Result
It arrives with no middle stop; the route is one printed line, pink to green.

5 · Clay Control Panel

Soft claymorphic 3D · glossy lamps · squash-and-stretch springs
Problem
After a change, one of four test lamps is red.
Action
The agent’s wrench tightens the loose part, then presses “Run tests”.
Result
Lamps flick on one by one until all four are green.

6 · Cardboard Stop-Motion Railway

Corrugated card · felt-tip labels · stepped 8–12 fps motion
Problem
You want to try two approaches without losing the first.
Action
At a labelled “Fork” switch, the conversation train splits onto two tracks.
Result
Two trains reach two stations (“Approach A” / “B”); you keep whichever works.

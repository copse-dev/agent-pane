Activity grouping — is “Recently finished” one bucket too few?

The desktop Activity panel (activity-model.ts) and the mobile Activity screen (mobile-activity.ts) already share one scheme: Needs you → Working → Recently finished. A thread that finished clean and one that finished with an uncommitted diff sitting unreviewed land in the same “Recently finished” bucket today, same weight, sorted only by recency. Going with flat split (Alt 2): “Has changes” earns its own top-level section between Working and Recently finished, rather than hiding one nesting level down — worth the extra section given it's a different ask from a clean finish (something to review/commit/ discard, not just a log entry). The per-row “N uncommitted” badge came out, though: once the section is titled “Has changes”, repeating the count on every row underneath is redundant chrome — the section heading already carries it. The badge stays reserved for Alt 4, the no-new-section fallback, where it's the only signal doing that job.

# `docs/`

This tree is the **contributor and design archive**: contracts, plans, threat
model, testing, and release engineering.

The **user manual** is [`user/`](user/README.md) — install, first run, approvals,
sandbox, troubleshooting. A hosted site at `copse.dev/docs/` is planned
([plans/docs-site.md](plans/docs-site.md)); do not file a how-to for end users
at this directory’s root.

Public-readiness decisions that still need an owner stamp live in
[public-readiness-decisions.md](public-readiness-decisions.md).

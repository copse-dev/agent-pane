## Auditor claims I checked and rejected

- `nice sudo cat /root/x` is **not** laundered (returns ineligible). Only the `env`/`xargs` wrapper case holds.
- `cat a && cd /opt && cat b` resolves targets correctly; the "ordered guard is a no-op" claim is wrong in effect.
- `cat <~/.ssh/id_rsa` is caught (as `external`) by an unrelated rule; not exploitable as described.

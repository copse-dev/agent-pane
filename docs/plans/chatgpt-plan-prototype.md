## Task brief

Users should be able to use their ChatGPT plan in Copse's own agent loop without
an API key or Codex ACP. Settings → Providers → OpenAI offers browser sign-in,
saved account selection, sign-out, and a usage link. The model picker offers the
selected account's live catalog as a separate ChatGPT-plan group. A thread's
model selection includes its registration ID so account switching cannot silently
change who pays for an existing thread.

Acceptance: fresh OAuth uses PKCE/state/nonce and a stable host ID; returning
sign-in reuses the issued client ID; only verified identities and granted direct
scopes allow inference; tokens never cross renderer IPC; credentials are encrypted
in settings; refreshes are serialized; requests obey the restricted plan contract;
tool results can continue a stateless conversation; failures never fall back to
API-key billing. Truncated streams cannot report successful completion.

This is a desktop prototype. Containers, automatic best-value selection, hosted
Responses tools, and replacing Codex ACP are excluded. Existing Copse permission
and tool execution policy is unchanged. Auth, persisted secrets and IPC require
the full `pnpm run check`, focused auth/transport/routing/component tests, and a
focused WebdriverIO visual eval. Real OAuth/inference requires a user account;
record it as unverified until performed.

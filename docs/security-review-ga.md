## Platform boundary changes since the prior review

Two landed changes move the boundary this ledger describes, so read every row
against them rather than against the July platform assumptions.

- **The project sandbox now runs on Linux as well as macOS.**
  [#1440](https://github.com/copse-dev/agent-pane/pull/1440) (`32379fdf`) added
  the bubblewrap backend and [#1449](https://github.com/copse-dev/agent-pane/pull/1449)
  (`4d5f8949`) carried the rollout follow-ups. `SANDBOX_PLATFORMS` in
  [`project-sandbox/state.ts`](../src/main/project-sandbox/state.ts) is now
  `['darwin', 'linux']`. Every “macOS-only” statement in the July ledger should
  be read as “macOS and Linux”; **Windows** is now the only unsandboxed
  platform, alongside a failed ASRT init on any platform.
- **A deterministic shell auto-approval classifier now grants some commands
  without a prompt.** [#1431](https://github.com/copse-dev/agent-pane/pull/1431)
  (`8e1f1bf3`) is a real change to the approval boundary H1 and #581 were closed
  against, and is recorded as N1 below.

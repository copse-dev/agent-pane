# Copse 0.1.0-beta.4 release-candidate checklist

Status: **Ready for beta promotion; signed artifact pending.**

Release owner and human security reviewer: **Jonathan Kingston**.

This is a narrow fix-forward candidate. Beta.3's signed arm64 and Intel apps passed notarization,
Gatekeeper, stapler, architecture, PTY, and thread-persistence checks in the release workflow and
again after mounting both downloaded DMGs on a separate Mac. Its checksum manifest used the CI
runner's `release/` prefix even though Actions downloads its contents at the artifact root. Every
byte matched after normalizing that prefix, but the shipped verification command was not directly
usable. Beta.4 changes the manifest layout and its artifact-only publisher; it does not change app
runtime code or replace beta.3 bytes.

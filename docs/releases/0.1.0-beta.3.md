# Copse 0.1.0-beta.3 release-candidate checklist

Status: **Signed binary validation complete; superseded by beta.4 for portable checksums.**

Release owner and human security reviewer: **Jonathan Kingston**.

This is a fix-forward candidate. `v0.1.0-beta.2` was cut immutably and its release workflow proved
the credentials, signing, notarization, Gatekeeper acceptance, stapling, and bundled gortex checks.
Its Intel packaged-runtime smoke then stalled because pnpm had installed only the build host's
Apple Silicon keyring binary. The run was cancelled before artifact upload or publication. This
candidate explicitly installs and verifies both macOS keyring architectures and bounds the
verification job.

# Copse 0.1.0-beta.5 release-candidate checklist

Status: **Ready for beta promotion; signed artifact pending.**

Release owner and human security reviewer: **Jonathan Kingston**.

This is a narrow fix-forward candidate. Beta.4's promotion and tag cut succeeded, but exact-release
CI timed out twice after `runReleaseSmokeTest` passed: the smoke path reported success while
node-pty could still be tearing down its helper, leaving the test worker alive until the job's
45-minute fail-closed timeout. The signed release workflow correctly refused to build without a
green exact-SHA aggregate. Beta.5 waits for the PTY exit before settling both the product smoke path
and its availability probe. It retains beta.4's basename-only checksum manifest fix.

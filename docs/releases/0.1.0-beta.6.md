# Copse 0.1.0-beta.6 release-candidate checklist

Status: **Lean per-architecture candidate; signed artifact validation pending.**

Release owner and human security reviewer: **Jonathan Kingston**.

Beta.5 proved the signing, notarization, Gatekeeper, stapling, architecture, packaged-runtime,
and portable-checksum paths, but its nominally architecture-specific downloads still carried a
large shared dependency tree and opposite-architecture native payloads. Each installer was
343–353 MiB and each installed app was roughly 1.3 GiB. Beta.6 splits the release build itself by
architecture, limits packaged production dependencies to runtime externals, strips release source
maps, removes the opposite keyring binary, and enforces download and installed-size budgets.

## Security and privacy gate

- [x] M3 remains fixed: blocking external command-hook failures default closed, explicit
      compatibility escapes remain, and external hooks are globally off by default.
- [x] L1 remains fixed: plaintext secret persistence requires
      `COPSE_ALLOW_PLAINTEXT_SECRETS=1` plus per-save consent.
- [x] The #2008 delta changes release packaging, dependency placement, update-feed assembly, size
      enforcement, and release documentation. It does not widen shell authority, credential
      access, publication permissions, telemetry, or persistent storage.
- [x] The optional `@huggingface/transformers` / ONNX runtime is no longer bundled. Heuristic PII
      redaction remains active by default; contextual transformer redaction is unavailable until
      an explicit on-demand installation path exists, as recorded in `docs/pii-redaction.md`.
- [x] Jonathan Kingston authorized cutting and validating beta releases on 2026-08-28.
- [ ] Record stable-GA sign-off only after signed/public/update evidence is complete.

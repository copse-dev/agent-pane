Copse

AI coding assistant for your desktop

Code with an agent that lives in your project

Copse is an Electron desktop app that chats with LLMs, runs tools against your workspace, and keeps you in the loop with approvals, diffs, and a full three-pane IDE layout. Use local models via LM Studio or cloud providers — no backend required.

See it in action

Screenshots captured from automated UI runs in this repository — the same views you get when running Copse locally.

Transparent tool use

Every agent action appears as a human-readable tool card. Related calls group together so a burst of file reads stays compact; expand any group to inspect individual steps.

  • Grouped labels like “Reading files ×2”
  • Expandable argument details
  • Clear error states for failed tools

Subagents for deep exploration

When the main agent needs to explore broadly, it can spawn subagents that run their own tool loops. Collapsed cards keep the timeline tidy; expand to follow nested work.

Git changes at a glance

The Changes panel lists staged, unstaged, and untracked files. Open inline diffs — including images — without switching to another app. Branch status appears in the footer and composer when your thread and git branch diverge.

Approve edits before they land

Agent-proposed file changes enter a staged-diff queue. Review hunks in Monaco, then accept or reject each change — nothing writes to disk until you approve it.

Monaco ↔ chat bridge

Select code in the editor and attach it directly to your prompt. Copse keeps file context, line ranges, and attachments visible in the composer.

Semantic code search

Ask questions in natural language and get ranked code hits from a project index. Results render as rich markdown explore cards inside the conversation.

Terminal & browser panes

The right panel switches between Explorer, Changes, Plan, Terminal, and Browser. Run shell commands beside the agent, or load a local dev server in the embedded browser.

In-app browser tabs

Open multiple browser tabs inside Copse for docs, staging sites, or quick visual checks while the agent keeps working in chat.

Plan & todos

The agent maintains a todo list and optional plan tab so you can track multi-step work across long sessions without losing the thread.

MCP servers on your terms

Copse is an MCP host: add servers in project or global config, see connection status in Settings, and approve tool calls before they run.

Model routing

Route everyday tasks to a fast local model and reserve cloud models for harder work. The onboarding wizard walks through API keys, LM Studio, and routing in a few steps.

Rich conversation UI

Mermaid diagrams, code blocks with copy buttons, follow-up suggestion chips, and a message queue while the agent is still running — polish that keeps long sessions usable.

  • Queue messages without interrupting the current turn
  • Context usage wheel in the footer
  • Export threads as JSONL for review

Get started

1

Prerequisites

Node.js 22 or newer. For the packaged macOS app, you need macOS and Xcode command-line tools. Optional: LM Studio for local models; Anthropic or OpenAI API keys for cloud models.

2

Clone & install

git clone https://github.com/jonathanKingston/agent-pane.git && cd agent-pane && npm install

npm install also fetches the bundled semantic-search binary on supported platforms.

3

Run in development

npm run dev

Opens the Electron app with hot rebuild. Use npm run build && npm start for a production bundle.

4

Build for macOS

npm run pack:mac

Produces an unpacked .app under release/. Open a project folder from the welcome screen or seed ~/.config/copse-panel/config.json on Linux.

Signed macOS and Windows installers are coming soon. For now, build from source with the commands above.

Why Copse?

Desktop-native

A real IDE layout — projects, chat, editor, terminal, and git — not a browser tab lost among dozens of others.

No backend

The Electron main process talks directly to LLM providers. Your code stays on your machine; API keys live in local settings.

You stay in control

Shell commands, MCP tools, and file writes go through approval gates. Staged diffs mean the agent proposes — you decide.

Hybrid models

Run everyday tasks on local hardware with LM Studio, then route complex work to cloud models when you need them.
